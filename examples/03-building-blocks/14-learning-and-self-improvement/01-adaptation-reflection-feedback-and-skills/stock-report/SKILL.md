# Stock report procedure

1. Identify the requested product and positive quantity. Clarify ambiguity.
2. Read the designated inventory source and record its snapshot identifier.
3. Compare known stock with the quantity. Report unknown when stock evidence is absent.
4. State availability and the source. Do not claim a reservation exists from availability evidence alone.
5. Check the report against the source before returning it.

This authored teaching package does not grant tool permissions, update weights or perform inventory writes. Its candidate version needs real held-out and retention evaluation before deployment.
