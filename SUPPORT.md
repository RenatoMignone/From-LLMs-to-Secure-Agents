# Support

This project is maintained in public on a best-effort basis.

- For usage questions and broad ideas, use [GitHub Discussions](https://github.com/RenatoMignone/From-LLMs-to-Secure-Agents/discussions).
- For reproducible defects or content problems, open an issue using the closest template.
- For sensitive security reports, follow [SECURITY.md](SECURITY.md) and do not post details publicly.

Before asking for help, search existing issues and discussions, check the live guide, and run the documented validation commands. Include the relevant file or page, expected behavior, actual behavior, and environment details when applicable.

The guide is educational material, not individualized security, legal, or compliance advice. Production decisions require review against the system, threat model, jurisdiction, and current primary sources involved.
