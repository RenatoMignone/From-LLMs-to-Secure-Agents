# Docs Instructions

Keep each policy file short and focused.

- Do not repeat rules from another file.
- Link to the authoritative file.
- Use simple English.
- Do not use em dashes.
- Update root `AGENTS.md` when adding or renaming a policy file.
- Keep operational status in `PROJECT_STATUS.md`, the stable queue in `ROADMAP.md`, and history in `CHANGELOG.md`.
