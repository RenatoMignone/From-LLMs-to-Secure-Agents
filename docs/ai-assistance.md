# AI Assistance and Editorial Responsibility

This project uses AI-assisted tools for research support, drafting, code changes, visual generation, and maintenance. AI assistance can accelerate work, but it does not establish that a claim is correct or that an example is safe.

## Project commitments

- A named human maintainer remains accountable for accepted changes and releases.
- Important claims must be checked against opened, canonical sources and linked through the source-record system.
- Generated code must pass the same tests and review as human-written code.
- Generated visuals must have local prompt provenance, meaningful alternative text, and human review for misleading details.
- Automated validation is treated as a consistency check, not proof of factual accuracy, security, or completeness.
- Draft and early-stage material is labeled honestly. Unfinished security coverage is not presented as production guidance.

## Contributor expectations

Contributors may use AI-assisted tools. They must understand and review the result, verify sources directly, respect licenses and privacy, and disclose material assistance in the pull request. Do not submit fabricated citations, private data, secrets, or content that you do not have the right to contribute.

Suggested disclosure:

> AI assistance was used for: [research organization, drafting, code, tests, or visuals]. I reviewed the changes, opened the cited sources, and ran the reported checks.

Minor spelling, formatting, or completion assistance does not need a detailed inventory. Material generation or transformation does.

## Known limits

The repository is a work in progress. Some published chapters have received more editorial review than others, and most planned security material has not yet been published. Readers should verify time-sensitive details against the cited primary sources and evaluate controls in their own environment.
