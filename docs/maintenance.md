# Maintenance

## Before editing

1. Read root `AGENTS.md`.
2. Read `PROJECT_STATUS.md` and `ROADMAP.md`.
3. Follow `docs/autonomous-workflow.md`.
4. Read the nearest local `AGENTS.md` and `chapter-plan.md`.
5. Read only the policies needed.
6. Define the learning outcome and identify the pass.

## After editing

1. Run `python3 scripts/validate_repo.py`.
2. Validate citations against source records.
3. Run examples, plot generators, and tests.
4. Check terminology and acronyms.
5. Check visual files, attribution, checksums, alt text, and captions.
6. Record limitations.
7. Confirm architecture chapters contain no detailed security content.
8. Confirm security chapters link to the threat model and Pass 1 architecture.
9. Update navigation.
10. Update `README.md`.
11. Update `PROJECT_STATUS.md` and append a concise `CHANGELOG.md` entry.

## Status values

- planned
- outline
- draft
- review
- complete
- deprecated
